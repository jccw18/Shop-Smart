###

User Stories:  

“As a college student, I try not to overspend. I want an app where I can put my daily expenses and bank account amount all in one place.”  

Functional: 

Our system will allow anyone to see their bank account or linked card amount on the home page. 

It will then have the user input their routine spending habit amounts on the same page. 

It will display the current amount in their accounts, which detracts from the amount the user spent. 

Non-Functional: 

The application needs to be able to calculate the user's input, and process at a minimum of less than 2 seconds.  

We want the application to make sure that it displays error messages whenever a non-integer is used. 

In addition to this, the application will currently only run and formatted using USD currency ($).  

The applications interface must have easy and clear instructions for new users.
